# Lightweight Todo App

Frontend-only todo app built with Next.js, Tailwind CSS, and shadcn/ui-style components.

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - start local dev server
- `npm run build` - create production build
- `npm run start` - run production server
- `npm run lint` - run lint checks

## Vercel deployment

1. Push this repo to GitHub.
2. Import the repo in Vercel.
3. Set `main` as production branch.
4. Vercel will create preview deployments for other branches/PRs.

No environment variables are required for v1.
